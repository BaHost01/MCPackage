# Support

Use the appropriate channel for the problem you are experiencing.

## Usage and setup

For installation, commands, project configuration, and normal troubleshooting:

1. Read the README and command help with `mcpackage --help`.
2. Search existing GitHub issues.
3. If the problem is reproducible and appears to be a bug, open a **Bug report** issue.
4. For usage questions that are not bugs, open a GitHub issue with the relevant environment and command details.

## Bug reports

Include:

- MCPackage version
- Node.js version
- operating system
- exact command
- expected behavior
- actual behavior
- relevant logs
- minimal reproduction steps

Remove passwords, access tokens, API keys, and other sensitive information before posting.

## Feature requests

Use the **Feature request** template and describe the use case and proposed behavior. Check existing issues first.

## Security issues

Do not post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
